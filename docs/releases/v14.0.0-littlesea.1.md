# Flameshot Enhanced v14.0.0-littlesea.1

本次发布是 [LittleSeaSir/flameshot-enhanced](https://github.com/LittleSeaSir/flameshot-enhanced) 的首个独立分支版本，基于 [Flameshot](https://github.com/flameshot-org/flameshot) 开发，非官方 Flameshot 发布。感谢原项目及其贡献者；主代码继续采用 GPLv3+，原有版权和第三方许可保留。

This is the first release of an independently maintained Flameshot fork. It is not an official upstream release. This RPM targets Fedora 44 x86_64 with KDE Plasma 6 on Wayland.

## 本分支包含的改进

- 平滑自由笔触，像素擦除和整笔擦除。
- 钉图保留截图位置；支持拖动、置顶和当前位置重新编辑。编辑期间背景锁定，确认后保留位置。
- 截图与钉图重新编辑保留原始像素，修复分数缩放导致的清晰度问题。
- 标注过程中仍可使用选区的 8 个控制点调整截图范围。
- 矩形、圆、直线等固定图形可以重新选中和移动。
- KDE Wayland 下自动识别鼠标所在窗口，单击选中，保留拖动自定义框选。

## 安装包与支持范围

- RPM：`flameshot-enhanced-14.0.0-1.littlesea.fc44.x86_64.rpm`
- 校验文件：`SHA256SUMS`
- 目标系统：Fedora 44，x86_64，KDE Plasma 6，Wayland。
- RPM 未进行 GPG 签名。请从本仓库 Release 下载，并核对 SHA-256；校验和仅验证文件完整性，不能代替签名。
- 此包依赖系统 Qt、KDE 和截图 Portal 组件，不保证兼容其他发行版、系统版本或架构。本次未发布 DEB 或 AppImage。

将 RPM 和 `SHA256SUMS` 保存到同一目录，先执行：

```sh
sha256sum --check --ignore-missing SHA256SUMS
```

确认 RPM 条目显示 `OK`。保存需要保留的截图和钉图，退出所有旧 Flameshot 进程，停止会自动重启旧进程的自定义服务。本包保留 `flameshot` 命令和服务标识，不能与官方 `flameshot` 包并存；如果已安装官方包，请先通过软件包管理器卸载。

在 Fedora 44 的下载目录安装：

```sh
sudo dnf install ./flameshot-enhanced-14.0.0-1.littlesea.fc44.x86_64.rpm
```

运行 `flameshot gui`，或从应用菜单启动。已有快捷键和自启动项如果指向旧构建、AppImage 或 Flatpak，需要更新到本次安装的程序。

## 已知限制

- 自动识别窗口依赖 KWin；其他桌面及无法读取窗口列表时使用整屏预选。
- GNOME Wayland、Sway、Hyprland、X11 尚未完成本分支的完整验证，尤其是钉图定位、置顶和重新编辑。
- 其他 RPM 发行版和 Fedora 版本需要分别构建和验证，不能根据文件格式推断兼容性。
- 安装新包不会关闭已经运行的旧程序。请在安装前退出旧实例，避免命令被旧进程接收。

## 从源码构建 RPM

在 Fedora 44 x86_64 安装构建依赖后，检出本发布标签并执行：

```sh
bash scripts/build-rpm.sh
```

脚本只打包干净、已提交的 Git 快照，默认使用两个并行编译任务。二进制 RPM
位于 `build/rpm/RPMS/x86_64/`，源码 RPM 位于 `build/rpm/SRPMS/`。
对应构建依赖和测试命令见 `packaging/rpm/flameshot-enhanced.spec`，自动构建配置
见 `.github/workflows/fork-rpm.yml`。
